# Bloom Beyond Events

A modern event-planning and booking platform for discovering experiences, exploring packages, and managing event enquiries.

## Features

- Event and package discovery
- Appointment and contact flows
- Authenticated administration area
- Supabase-backed application services

## Technology

React, TypeScript, TanStack Start, Vite, Tailwind CSS, and Supabase.

## Run locally

```bash
bun install
cp .env.example .env
bun run dev
```

Fill the environment values with your own Supabase project configuration. Never commit `.env` files.

## Build

```bash
bun run build
```
